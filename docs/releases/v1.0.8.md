# v1.0.8 — 功能闭环、边界修复与口径统一

本版把上一轮全项目检查确认的问题修完，并补上两个此前断掉的功能闭环：**在页面上建公司**、
**推进客户采用进度**。数据库结构不变（仍为 schema v7），升级不需要迁移。

> 本版为正式补丁版本：GitHub Release 的 Latest 与容器镜像 `latest` 均指向 `1.0.8`。
> 如需回滚，把 compose 的 `image:` 改回 `1.0.7` 即可（数据库结构相同，可直接用同一份数据卷）。

## 主要修改

### 高：会导致 500、数据丢失或功能不可用

- **变更日志空白关键词 500**：`/admin/logs?q=+`、`/api/v1/audit?q=%20` 不再抛
  `AttributeError`；空关键词等价于「不筛」。
- **`seed --force` 在已有客户采用记录时崩**：清理顺序改为「引用方 → 被引用方」，
  不再触发 SQLite 外键错误。
- **空库可在页面上建第一家公司**：新增 `POST /companies` 与产品管理页表单；
  同名（忽略空格/标点/大小写/括注）与第二个 `self` 会被拦住。
- **客户采用可推进进度**：新增 `POST /products/{id}/adoptions/{aid}` 与行内编辑器，
  从「传闻」一路改到「已停用」，审计里记「状态 送样 → 量产」这样的差异。
- **导入模板列宽修正**：示例行与表头同为 22 列，下载的 xlsx/csv 不再多出两列空白。

### 中：一致性、边界与可维护性

- 变更日志翻页对全部筛选值做 URL 编码，关键词含 `&`/`#` 不再丢条件。
- 系统设置「上次修改」与备份导出的时间列改按部署时区显示。
- 规格书页的公司名归一与后端 `entity_names.key` 对齐（括注不另算一家）。
- 公司/型号查找收口到 `app/lookups.py`，页面、API、导入共用一份实现。
- `/api/v1/entities` 支持 `limit` 与 `cursor`，返回 `count/has_more/next_cursor`
  （`total` 保留，向后兼容）。
- `/api/v1/tools` 补 `create_entity`（共 19 个工具），状态枚举改由模型层提供。
- 审计与幂等记录的过期清理改为单条 `DELETE`，不再把过期行全部载入内存。
- 完整度计算遇到已删除的型号 id 时降级为 0，不再 `KeyError`。
- 纯文本规格书按**字符数**判解析上限（中文不再被按字节误判超限）。
- 维护脚本 `align-entity-meta.py` 默认指向本机、缺 `CIB_TOKEN` 给出人话并退出 2、
  首次请求失败不再 traceback。
- `?cat=` 深链真正生效（tab 高亮与表格过滤同步）；非法值回落「全部」。
- 修正「删除型号后来源记录保留」的错误文案。

### 低：死代码、格式与文档

- 把 `REQUIRED_META` 变成表头校验的唯一来源，并删除其它死代码：
  `routes_datasheet.SHEET_EXT`、MCP 不可达分支、失效 CSS 选择器；合并重复的
  `body` / `.pill-ok` 规则，补 `.empty-mark` 样式。
- `main.py` 抽出 `_is_api_v1()` 统一路径判断；405 错误码改为 `METHOD_NOT_ALLOWED`；
  修正孤立注释与函数间空行。
- `audit._s` 改名 `as_text`；`TokenIn.scopes` 去掉可变默认值；
  `backend/app/__init__.py` 删除与 `app.version` 漂移的 `__version__`。
- 修正 README 的 MCP 工具数（14 → 19）、补 `/companies` 与采用关系路由；
  修正 `docs/AI-API-设计.md` 中「不做审计日志」「不透传 If-Match」两处与实现相反的表述。

## 兼容性

| 项目 | 变化 |
|---|---|
| 数据库结构 | **不变**，仍为 schema v7；升级不触发迁移，回滚到 1.0.7 也可直接打开 |
| 页面路由 | 新增 `POST /companies`、`POST /products/{id}/adoptions/{aid}`；原有路由不变 |
| `/api/v1` | 新增 `create_entity` 工具、entities 分页参数；响应只增字段，`total` 保留 |
| 时间格式 | 接口里的时间统一为带 `+00:00` 的 ISO 8601（此前部分接口不带时区） |
| 行为 | 导入模板列宽修正；`seed --force` 会连同采用关系一起清空后重建 |

## 升级注意事项

- 升级前备份数据库与 `datasheets` 原文目录（本版不改结构，但备份是升级前的固定动作）。
- 启动日志**不应**出现 `表结构 6 → 7`；若出现，说明连到了比预期更旧的库。
- 仓库里的 `docker-compose.yml` 已随版本改为 `1.0.8`，`latest` 也指向本版。
  需要回滚时把 `image:` 改回 `1.0.7` 再 `docker compose up -d` 即可。

```bash
git pull --ff-only
docker compose pull
docker compose up -d
docker compose logs -f app
```
