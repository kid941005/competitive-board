# v1.5.1 — 结构化运行日志、请求 ID 与液态玻璃界面

本版把运行日志从「零散 print + uvicorn 默认文本」换成**一行一个 JSON 的结构化日志**：
每条请求带级别、请求 ID、方法、路径、状态码、耗时与登录用户；请求 ID 同时回写
`X-Request-ID` 并在页脚显示，用户报问题时可以直接拿页脚 ID 去日志里搜。
界面同时换成**液态玻璃**视觉层：顶栏、面板、表格、登录卡、新闻卡与表单统一半透明玻璃质感，
亮色 / 深色 / 跟随系统三档都适配；样式独立在 `liquid-glass.css`，不改原有布局契约。
数据库仍是 **schema v9**，不新增迁移；页面路由不变，`/api/v1` 的 `meta.request_id`
改为与访问日志、审计记录同源。

> GitHub Release 的 Latest 与容器镜像 `latest` 均指向 `1.5.1`。
> 从 v1.4.0 升级只需换镜像标签，无需备份迁移；回滚同理。

## 主要修改

### 高：结构化访问日志（请求 ID / 级别 / JSON）

- 新增 `backend/app/logging_setup.py`：`JsonFormatter` 输出单行 JSON，
  `request_id` 放在 contextvar 里，业务代码与模板无需层层传参。
- 新增请求中间件：优先复用上游 `X-Request-ID`（只接受 1–64 位安全字符），
  否则生成 12 位随机串；响应回写 `X-Request-ID`，页脚展示同一个 ID。
- 每个请求记录 `ts / level / logger / request_id / event / msg / method / path /
  status / duration_ms / client / user / role`；4xx 记 warning、5xx 记 error；
  `/static/` 的 200 降到 debug，避免静态资源刷屏。
- 未处理异常额外带 `exc_type / exc_message / exc_stack`，同一条 JSON 内可检索。
- `uvicorn.access` 关闭，访问日志统一由中间件输出，避免一半 JSON、一半 uvicorn 文本。
- 启动/后台任务日志一并结构化：`schema_migrate`、`news_seed`、`news_refresh`、
  `news_link_backfill`、`datasheet_purge`、`bootstrap_admin` 等事件名。
- 配置：`CIB_LOG_LEVEL`（默认 `INFO`）、`CIB_LOG_FORMAT`（默认 `json`，
  本地可设 `plain`）。

### 高：液态玻璃界面（liquid-glass.css 覆盖层）

- 新增 `backend/app/static/liquid-glass.css`，在 `app.css` 之后加载；只覆盖设计令牌与视觉层，不改 `.table-wrap` 等布局契约（`test_ui_contract` 仍直接校验 `app.css`）。
- 玻璃基底：`backdrop-filter: blur(22px) saturate(180%)`、半透明色、1px 高光描边、双层阴影与内高光；亮色、深色、`data-theme="auto"` 三套令牌完整。
- 覆盖顶栏、导航胶囊、面板、表格、登录卡、新闻卡、消息源列表、设置表单、按钮 / 输入框、chips / tabs、flash、页脚、浮层与主题选择器。
- 无 `backdrop-filter` 时用 `@supports not` 降级为不透明玻璃色；`prefers-reduced-motion` 关闭过渡；≤640px 继续沿用既有自适应并补齐玻璃组件间距。
- 宽屏（≥1200px）不再把内容锁在 1680px：页面铺满窗口，顶栏导航收成内容宽并居中，消息时间线放宽到 1400px，消除两侧大面积空白与顶部 dock 拥挤。
- 消息时间轴的竖线改为贯通所有日期组（不再按天分段），日期标题左移让出轨道，滚动与折叠时保持整条连续。

### 中：请求 ID 贯穿响应与页脚

- `/api/v1` 的 `meta.request_id`、审计记录 `request_id` 与访问日志使用同一个值，
  用户拿到响应里的 ID 就能直接定位那一条请求。
- 页脚由「看板名 + 版本号」改为「看板名 + 请求 ID + 版本号」；版本号继续与
  `app.version` 同源，不需要额外配置。

### 低：测试与文档

- 新增 `backend/tests/test_logging.py`（6 项）：JSON 字段、请求 ID 复用与非法值替换、
  访问日志含状态/耗时/用户、`/api/v1` 信封同源、404 页面页脚带请求 ID。
- 新增 `backend/tests/test_liquid_glass.py`（3 项）：样式链接顺序、核心令牌 / 组件覆盖存在、静态资源可访问。
- README 增加「运行日志」整节：字段表、示例 JSON、排错顺序与两个环境变量；功能列表补「液态玻璃界面」。

## 兼容性

| 项目 | 变化 | 说明 |
|---|---|---|
| 数据库结构 | 不变（v9） | 无新表、无新列、无迁移 |
| 页面路由 | 不变 | 仅页脚多显示请求 ID |
| `/api/v1` | 仅 `meta.request_id` 取值来源变 | 值与访问日志/审计记录同源，格式不变 |
| 日志格式 | **默认 JSON 行** | 原来混用的 `print` / uvicorn 文本不再出现；需要人读可设 `CIB_LOG_FORMAT=plain` |
| 响应头 | 新增 `X-Request-ID` | 上游传入的安全 ID 会被复用，便于链路追踪 |
| 页面外观 | 新增液态玻璃覆盖层 | HTML 结构、页面路由、数据库均不变；`app.css` 的布局契约不变，可单独回滚 `liquid-glass.css` |
