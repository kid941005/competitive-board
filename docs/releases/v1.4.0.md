# v1.4.0 — 主题切换与自适应界面

本版是**纯前端体验版本**：新增「跟随系统 / 浅色 / 深色」三档主题，顶栏右侧下拉框即切即生效、
选择记在本机；同时补了 ≤640px 的窄屏布局（顶栏换行、导航横向滑动、表单与卡片单列）。
数据库仍是 **schema v9**，不新增迁移；`/api/v1` 与页面路由均未改动。

> GitHub Release 的 Latest 与容器镜像 `latest` 均指向 `1.4.0`。
> 从 v1.3.0 升级只需换镜像标签，无需备份迁移；回滚同理。

## 主要修改

### 高：主题切换（跟随系统 / 浅色 / 深色）

- **三档选择**：顶栏用户区新增下拉框，`跟随系统` 为默认值；选择写入
  `localStorage["cib-theme"] = auto | light | dark`，刷新、换页都保持。
- **无闪烁（FOUC）**：`base.html` 在**首个样式表之前**放了一小段内联脚本，先按同样的规则把
  解析结果写到 `<html data-theme="light|dark">`；深色用户不会先看到一帧白底。
  禁用 JS 时由 CSS 的 `@media (prefers-color-scheme: dark)` + `[data-theme="auto"]` 兜底。
- **CSS 只认 `data-theme`**：原来散落的 5 处 `@media (prefers-color-scheme: dark)` 补丁全部改成
  `:root[data-theme="dark"] …` 规则，并保留一份 `:root[data-theme="auto"]` 的媒体查询给无 JS 场景。
  换主题只改属性，不重载页面。
- **跟随系统会实时响应**：`matchMedia('(prefers-color-scheme: dark)')` 变化时，仅当选择是
  `auto` 才重新解析；显式选了浅色/深色就不被系统设置覆盖。
- 新增 `backend/app/static/theme.js`（约 70 行，零依赖）；`base.html` 以
  `/static/theme.js?v=<app.version>` 引入，随版本号破缓存。

### 中：自适应（窄屏）

- 新增 `@media (max-width: 640px)`：顶栏改为「品牌 + 用户区」一行、导航换到独立一行并
  **横向滑动**（隐藏滚动条）；页脚与内容边距收窄。
- 表单统一单列：`userform` / `clip-row` / `ds-field` 竖排、按钮占满宽度；
  筛选下拉占满可用宽度，搜索框与输入框不再有 180~240px 的固定最小宽度。
- 报告网格 `rcell` 变两列；`panel-head` 允许换行，操作按钮不再被挤出屏幕。
- 900px 一档的既有规则（侧栏让位、表格横向滚动）保持不变。

### 低：文档与测试

- 新增 `backend/tests/test_theme.py`（5 项）：三档选项与默认值、内联脚本在样式表之前、
  `theme.js` 被引入、CSS 有 `data-theme` 作用域与 640px 断点、`theme.js` 契约
  （`cib-theme` / `matchMedia` / `data-theme-pref` / `localStorage.setItem`）。
- README 增加主题与自适应说明，界面预览沿用现有截图。

## 兼容性

| 项目 | 变化 | 说明 |
|---|---|---|
| 数据库结构 | 不变（v9） | 无新表、无新列、无迁移 |
| 页面路由 | 不变 | 仅顶栏新增下拉框；登录/权限逻辑未动 |
| `/api/v1` | 不变 | 不涉及 |
| 静态资源 | 新增 `/static/theme.js` | `app.css` 深色规则改为 `data-theme` 作用域 |
| 浏览器行为 | 记住本机主题 | 存 `localStorage`，清站点数据后回默认「跟随系统」 |
| 无 JS 场景 | 降级可用 | 跟随系统外观，无法手动切换 |
