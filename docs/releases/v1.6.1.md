# v1.6.1 — 消息源默认语言、Google News 代理与自适应时间线

本版补上两个日常使用中的小缺口：新增消息源时语言默认中文，以及给打不开 `news.google.com` 的部署环境一个只对 Google 生效的代理开关；同时让市场消息时间线随内容区域自适应宽度，不再固定 `max-width`。
数据库仍是 **schema v9**，不新增迁移；页面路由不变；`/api/v1` 不变。

> GitHub Release 的 Latest 与容器镜像 `latest` 均指向 `1.6.1`。
> 从 v1.5.1 升级只需换镜像标签，无需备份迁移；回滚同理。

## 主要修改

### 高：新增消息源默认语言

- 系统设置新增 **新增消息源默认语言**（`news.default_lang`，默认 `zh`，可选 `en`）。
- `/admin/news` 的「新增消息源」表单按该设置预选语言；只影响新表单，已有消息源的语言字段不改。

### 高：Google News 抓取代理

- 系统设置新增 **Google News 抓取代理**（`news.google_proxy`，默认空 = 直连）。
- 代理**只对 `news.google.com` 生效**：覆盖 7 个 Google News 检索源的 RSS 抓取与原文地址解析；官网 RSS、手工补录和其它国内站点仍直连，避免把本来能直连的源拖慢。
- 地址校验只接受 `http(s)://主机:端口`（可带账号密码），带路径或缺少 scheme 会被拒绝并提示原因。
- 实现位置：`news_fetch.fetch_feed(..., proxy=)`、`news._proxy_for()`、`news_link._open(..., proxy=)` 与后台 `backfill`。

### 低：时间线自适应宽度

- `/news` 时间线不再固定 `max-width`（原 920px / 宽屏 1400px 上限均移除），改为 `width: 100%` 随内容区域铺满，宽屏下不再留下两侧空白。
- 只改 `liquid-glass.css` 的布局覆盖，不改 `app.css` 的既有 sticky 表格契约；日期组头、时间轴竖线与卡片栅格保持原样。

### 低：测试与文档

- `test_news` 增加默认语言、代理校验、代理只随 Google 源传递、`fetch_feed` 构建 ProxyHandler 的用例。
- `test_news_link` 增加解析链路把 proxy 透传给两次请求的用例。
- README 增加「消息源默认语言与 Google News 代理」小节。

## 兼容性

| 项目 | 变化 | 说明 |
|---|---|---|
| 数据库结构 | 不变（v9） | 无新表、无新列、无迁移 |
| 页面路由 | 不变 | 仅 `/admin/news` 的语言下拉默认值和 `/admin/settings` 多两项配置 |
| `/api/v1` | 不变 | 请求/响应格式未改 |
| 配置项 | 新增两项 | `news.default_lang`（默认 `zh`）、`news.google_proxy`（默认空） |
| 抓取行为 | Google 源可选走代理 | 未配置代理时与旧版完全一致 |
